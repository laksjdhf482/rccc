# RPG 자동차 주차·도로주행 게임

Python + Streamlit으로 제작하는 자동차 운전·주차 RPG 게임 프로토타입입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run main.py
```

## 조작

- ↑: 전진
- ↓: 후진
- ←: 왼쪽 조향
- →: 오른쪽 조향
- Space: 1인칭 / 3인칭 전환
- Enter: 현재 미션 종료 및 결과 계산

## 현재 구현

- 자유주행
- 운전면허시험
- 주차 모드
- 모닝 / 승용차 / SUV / 1톤 트럭 / 대형 트럭
- BMW / 캐딜락 에스컬레이드 / 스포츠카 구매 시스템
- 돈 획득 및 차량 구매
- 단계 상승
- 랜덤 주차 위치와 주변 차량
- 시간 측정
- 주차 위치 오차 및 각도 오차 측정
- 1인칭 시점의 백미러 / 사이드미러 UI
- 3인칭 시점
